## Открытые вопросы

1. **API однажды перестал отвечать (29.10, ноутбук) — исправлено, наблюдаем.** Вероятная причина: `node --watch`
   следил и за `node_modules`, а на Windows его будило даже чтение файлов антивирусом («Change detected» в
   `@prisma/client` и `sharp` без изменений) — лишний перезапуск однажды упал. С вашего «да» `start:dev` теперь
   `node --watch-path=src …`: следит только за `src` (проверено: `node_modules` перезапуск не вызывает, `src` — вызывает).
   После `npm install` или `npx prisma generate` API нужно перезапустить вручную (`stop.bat` → `start.bat`).
