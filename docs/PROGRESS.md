## Открытые вопросы

1. **API однажды перестал отвечать (29.10, ноутбук).** Окно «VITALO API» было открыто, но сервер внутри упал, а
   `node --watch` ждал изменения файлов. `--watch` следит за всеми загруженными файлами, включая `node_modules`; на
   Windows его будит даже чтение файлов антивирусом — было видно «Change detected» в `@prisma/client` и `sharp`, хотя
   файлы не менялись. Вероятно, один из таких лишних перезапусков упал (старый процесс ещё держал порт 3000 или файл
   был занят). Точно подтвердить нельзя: лог окна не сохранился.
   **Предложение (ждёт «да», код не менялся):** в `apps/api/package.json` заменить `start:dev` на
   `node --watch-path=src -r ts-node/register src/main.ts` — следить только за папкой `src`. Минус: после
   `npm install` или `npx prisma generate` API надо перезапустить вручную (`stop.bat` → `start.bat`).
   Пока: если API не отвечает — `stop.bat` и `start.bat`.
2. **Миграции.** На ноутбуке не применены 4 миграции (`20261015…`–`20261029…`); на сервере не применена только
   `20261029…` (её нет в выложенном коде). Применять — только с разрешения.
