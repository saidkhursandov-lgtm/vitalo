# VITALO AI — знания для проверки совместимости (подэтап 3.8, шаг 1)

Состояние на 02.11.2026 в базе разработки `vitalo_dev`. Спецификация — [vitalo-ai.md](vitalo-ai.md), решение D-45.

**Что нужно от владельца:**

1. Проверить справочник веществ (раздел 1) и «товар → вещества» (раздел 2). Поправить можно сразу в админке:
   «Совместимость → Вещества» и «Совместимость → Товары и вещества».
2. Проверить правила (раздел 3) и **одобрить** их в админке «Совместимость → Правила» (по одному или кнопкой
   «Одобрить все черновики»). Пока правило — черновик, VITALO AI его не видит.

**Откуда данные:**

- Справочник веществ — стартовый список (миграция `20261109100000_stage38_vitalo_ai`); правится в админке.
- Правила 1–16 — лист «Правила совместимости» из `docs/content/VITALO_catalog.xlsx` (строка-пример «кальций (ПРИМЕР)»
  пропущена); правила 17–25 — предложения VITALO.
- Вещества товаров — по составу из карточки (`label_composition_ru`). Столбец «Действующие вещества» на листе «Товары»
  в таблице пока пустой у всех товаров.
- Загрузка — `npm run compat:knowledge` (сначала предпросмотр, затем `--apply`); существующее не меняет.

**Как правила применяются:** правило срабатывает, только когда вещества A и B находятся в **разных** товарах корзины.
Например, цинк и железо внутри одного мультивитамина правило «разнести» не включают. Форма вещества получает его
правила (P-5-P — форма B6).
