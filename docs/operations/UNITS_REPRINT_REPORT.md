# «Единицы»: перепечатка этикеток пачкой — короткий отчёт

Решение: [DECISIONS.md](DECISIONS.md), S2B-9. Коммиты локальные, без push. На сервер я не заходил, на `vitalo_dev` ничего
не запускал. Тесты — только на `vitalo_test`. **Миграции нет.**

## Что сделано

В **Склад → Единицы**:

- галочка у каждой строки;
- верхняя галочка — **«выбрать все на странице»** (на странице до 50 банок);
- кнопка **«Напечатать этикетки выбранных (N)»** и «Снять выбор».

Кнопка открывает ту же страницу печати, что и «Напечатать этикетку» в карточке банки, только сразу на все выбранные.
Сервер не менялся: используется уже существовавшая печать пачкой.

## Что происходит при печати

- печатаются **существующие** банки с их Physical ID — новые банки не создаются;
- остатки, статусы, сроки, себестоимость и сами Physical ID **не меняются**;
- в историю каждой банки добавляется строка «Напечатана этикетка»;
- счётчик «Этикеток» у каждой банки увеличивается на 1.

## Ограничения

- **До 50 этикеток за раз** (на странице как раз 50 строк). Если банок больше — печатайте страницу за страницей.
- **Отменённую банку выбрать нельзя** — у неё галочка недоступна: этикетка такой банке не нужна.
- Выбор сбрасывается при смене страницы или фильтра — чтобы случайно не напечатать то, чего не видно на экране.
- **Роли — как у печати одной этикетки:** администратор, менеджер, склад. Маркетолог вкладку «Единицы» не видит.

## Как напечатать ваши 49 банок

1. **Склад → Единицы**, в фильтре статуса выберите «На складе» (или оставьте «Все статусы»).
2. Нажмите верхнюю галочку — отметятся все банки на странице. Лишние можно снять по одной.
3. **«Напечатать этикетки выбранных (49)»** — откроется вкладка печати.
4. В окне печати: принтер Xprinter, бумага по размеру этикетки (по умолчанию 58×40 мм), масштаб 100 %, поля «Нет».
5. Вернитесь в «Единицы»: в колонке «Этикеток» у этих банок число выросло на 1.

Если вкладка печати не открылась — браузер заблокировал всплывающее окно: разрешите всплывающие окна для админки и
нажмите кнопку ещё раз. В Telegram страница печати откроется во внешнем браузере, как и раньше.

Размер этикетки не менялся (Настройки → Печать). Если ваш рулон другого размера — сначала поставьте его там и сделайте
«Тестовую печать этикетки» на экране приёмки.

## Как выкатить на сервер

Миграции нет, поэтому `update.sh` без `--migrate`.

**1. На компьютере — отправить код** (магазин при этом не меняется):

```powershell
cd C:\Users\PC_LENOVO\Documents\VITALO\vitalo
& "C:\Program Files\Git\cmd\git.exe" push server main
```

Хорошо: в конце `main -> main`.

**2. На сервере — резервная копия:**

```bash
sudo -iu vitalo /opt/vitalo/app/deploy/scripts/backup.sh
```

Хорошо: строка `База: … проверена`.

**3. Посмотреть, что придёт (ничего не меняет):**

```bash
sudo -iu vitalo /opt/vitalo/app/deploy/scripts/update.sh --check
```

Хорошо: «Новых миграций нет». Если в списке есть `20261016100000_yandex_ship_by` или
`20261017100000_order_delivery_waybill` — значит, прошлые обновления ещё не выкатывались; тогда в следующей команде
добавьте `--migrate` (обе только добавляют колонки).

**4. Обновить:**

```bash
sudo -iu vitalo /opt/vitalo/app/deploy/scripts/update.sh
```

Хорошо: последняя строка «API отвечает. Готово.»

**5. Проверить:**

```bash
sudo /opt/vitalo/app/scripts/server/healthcheck.sh
```

Хорошо: «ИТОГ: всё в порядке». В админке → Склад → Единицы появились галочки и кнопка.
