# Печать этикеток 75×120 мм на XPrinter XP-365B

Инструкция для того, кто будет печатать этикетки на складе. Программировать ничего не нужно.

Этикетка печатается **из браузера Chrome** прямо из админки VITALO: одна этикетка — одна страница 75×120 мм,
книжная ориентация. На этикетке: Physical ID крупно, штрихкод, SKU, короткий состав RU и UZ, срок годности.

> Названия кнопок в драйвере могут немного отличаться в зависимости от его версии. Если что-то выглядит иначе,
> ищите похожий пункт по смыслу.

---

## 1. Установить драйвер на Windows

1. Подключите принтер кабелем USB к компьютеру и включите его.
2. Скачайте драйвер XP-365B **с официального сайта XPrinter** (раздел Download / Driver, модель XP-365B,
   Windows). Драйверы с других сайтов не ставьте.
3. Запустите установщик, выберите модель **XP-365B** и порт **USB** (обычно `USB001`). Дождитесь окончания установки.
4. Откройте **Пуск → Параметры → Bluetooth и устройства → Принтеры и сканеры**: в списке должен появиться XP-365B.
5. Нажмите на принтер → **Печать пробной страницы**. Если страница вышла, принтер работает.

## 2. Задать размер бумаги 75×120 мм

Размер нужно задать один раз — в драйвере принтера.

1. **Принтеры и сканеры → XP-365B → Настройки печати** (Printing Preferences).
2. Вкладка **Page Setup** (или «Бумага»/«Stock»): нажмите **New** (Создать) и введите:
   - название: `VITALO 75x120`;
   - ширина (Width): **75 мм**;
   - высота (Height): **120 мм**;
   - если спрашивают единицы — выберите **мм**.
3. Выберите этот размер, ориентация **книжная** (Portrait). Нажмите **OK / Применить**.
4. Там же (если есть):
   - тип бумаги / датчик (Media type / Sensor): **Labels with gaps** — «этикетки с промежутками» (Gap);
   - плотность печати (Darkness): **8–10**;
   - скорость (Speed): **2–3** (медленнее — чётче штрихкод).

Если в драйвере нет кнопки New: **Принтеры и сканеры → Свойства сервера печати → вкладка «Формы» →
«Создать новую форму»**, задайте 7,50 × 12,00 см, сохраните и выберите эту форму в настройках печати XP-365B.

## 3. Калибровка датчика промежутков

Принтер должен «знать», где кончается одна этикетка и начинается следующая. Калибруйте после установки и
**каждый раз, когда ставите новый рулон** другого размера.

1. Вставьте рулон этикеток 75×120, закройте крышку.
2. Выключенный принтер: зажмите кнопку **FEED** и включите питание; отпустите кнопку, когда индикатор начнёт
   мигать. (На некоторых прошивках: на включённом принтере держите FEED 2–3 секунды до сигнала.)
3. Принтер протянет несколько этикеток и остановится ровно на начале следующей — калибровка готова.
4. Нажмите FEED один раз коротко: должна выйти **ровно одна** этикетка. Если выходит больше или останавливается
   посередине — повторите калибровку. Точный порядок кнопок — в инструкции к принтеру.

## 4. Настройки Chrome при печати

Когда в админке нажимаете «Напечатать этикетки», открывается страница с этикетками и окно печати Chrome.
Проверьте (Chrome запомнит выбор):

| Поле | Значение |
| --- | --- |
| Принтер | **XP-365B** |
| Страницы | Все |
| Ориентация / Макет | **Книжная** |
| Ещё настройки → Размер бумаги | **VITALO 75x120** (или 75 × 120 мм) |
| Поля | **Нет** |
| Масштаб | **По умолчанию** (= 100%). Не «По размеру страницы» |
| Колонтитулы | **выключить** (снять галочку) |
| Фон | можно оставить как есть |

Если на этикетке появились дата, адрес страницы или номер страницы — включены колонтитулы, снимите галочку.
Если всё мелкое или съехало — проверьте, что масштаб 100% и поля «Нет».

## 5. Тестовая печать и проверка

1. Админка → **Склад → Приёмка → «Тестовая печать этикетки»** (или адрес `/print/test`). Данные на ней вымышленные,
   в журнал ничего не пишется.
2. Оставьте галочку «Разметка для калибровки» и нажмите «Печать». На этикетке будут:
   - **сплошная рамка** — край этикетки 75×120 мм;
   - **пунктир** — безопасное поле 2 мм: весь текст должен быть внутри;
   - **риски** сверху и слева — каждые 10 мм: приложите линейку, между соседними рисками должно быть ровно 10 мм.
3. Если рамка обрезана или смещена — повторите калибровку (раздел 3) и проверьте размер бумаги (раздел 2).
4. Проверьте буквы: на тестовой этикетке есть узбекские **o‘** и **g‘** — они должны печататься нормально.

## 6. Проверка штрихкода

- На этикетке штрихкод **Code 128**, в нём записан Physical ID (например, `V-012345`).
- Проверка без сканера: откройте на телефоне любое приложение «сканер штрихкодов» и наведите на штрихкод — должно
  прочитаться то же, что напечатано крупно над ним.
- Проверка со сканером (когда появится USB-сканер): админка → **Склад → Единицы**, курсор уже стоит в поле
  «Physical ID». Отсканируйте этикетку — сканер «напечатает» номер и нажмёт Enter, откроется карточка единицы.
  Если сканер не нажимает Enter сам — нажмите Enter вручную или включите в сканере суффикс Enter (по его инструкции).
- Если штрихкод не читается: увеличьте плотность (Darkness), уменьшите скорость, почистите печатающую головку
  спиртовой салфеткой.

## 7. Обычная работа

1. Склад → Приёмка → выбрать источник → «Принять» → количество и сроки годности → **«Создать Physical ID»**.
2. **«Напечатать этикетки»** — откроется страница и окно печати; каждая печать записывается в историю единицы.
3. Наклеить этикетки на банки → ответить **«Да, наклеены»** → **«Завершить приёмку»**.
4. Перепечатать одну этикетку: Склад → Единицы → найти номер → **«Напечатать этикетку»**.
