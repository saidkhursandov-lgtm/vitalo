# План: товары по поставщикам и «под заказ» у любого поставщика (D-61)

Решение владельца 09.11.2026. Обобщает этап 6 «Под заказ из США» (D-60): вместо одного «iHerb / из США» — поставщики
разных видов, у каждого свои сроки. Ветка: `supply-sources` от `main`.

## Как сейчас работает бизнес

| Поставщик | Вид | Как продаём |
| --- | --- | --- |
| Ozon (аккаунты Ozon) | закупка на склад | держим склад в Ташкенте, продаём «В наличии» |
| iHerb | из-за рубежа (США), доставка в Ташкент | при нуле на складе — «Под заказ из США • 7–14 дней», гарантия 21 день |
| Amazon и другие (позже) | из-за рубежа, везут курьеры | так же, со своими сроками и гарантией |
| Glorious Healthy Nutrition MChJ | местный | и на склад, и под заказ, когда на складе ноль |

## Ответы владельца

1. Товары и бренды делим **вкладками** в одном разделе: «Все / Ozon / iHerb / Glorious Healthy Nutrition / …»,
   плюс колонка «Поставщик». Новый поставщик — новая вкладка, без программиста.
2. Glorious Healthy Nutrition — **и так, и так**: часть товара на складе, а когда кончилось — под заказ у них.
3. Товар бывает у нескольких поставщиков (`VTL-GH…`: Glorious и iHerb). **Откуда продавать при нуле на складе,
   владелец выбирает сам в карточке товара.**
4. У каждого зарубежного поставщика **свои сроки и гарантия** («Под заказ из США • 14–25 дней» у Amazon).

## Что меняется

**Поставщики** (справочник «Поставщики» расширяется, только добавлением полей):
- вид: «Ozon (склад)», «местный», «из-за рубежа»; для зарубежного — страна («США»), по ней пишется «из США»;
- для «под заказ»: срок «с–по» дней от оплаты и гарантия (через сколько дней можно отменить с возвратом);
- iHerb становится обычным поставщиком вида «из-за рубежа, США, 7–14, гарантия 21» — настройки из «Сроки и гарантия»
  переезжают в его карточку. Ozon — отдельная вкладка по Ozon-аккаунтам, как сейчас в закупках.

**Товар:**
- «Где берём»: список поставщиков товара (можно несколько) — с артикулом или ссылкой у поставщика (ссылка iHerb уже есть);
- «Если на складе ноль»: «Нет в наличии (лист ожидания)» или «Под заказ у …» — выбор из поставщиков товара;
- переход: товарам с галочкой «Под заказ из США» и артикулом `VTL-H…`/`VTL-GH…` миграция сама ставит «Где берём: iHerb»
  и «Если ноль: под заказ у iHerb»; `VTL-GH…` получает ещё Glorious. Владелец потом меняет, если нужно. Правило по
  артикулу после этого больше не нужно: решает выбор в карточке.

**Покупатель:**
- «Под заказ из США • 7–14 дней» — для зарубежного; «Под заказ • 1–2 дня» — для местного;
- трекинг: для зарубежного — как сейчас (заказан у поставщика → отправлен из страны → прибыл в Узбекистан → на складе);
  для местного — короче (заказан у поставщика → на складе);
- гарантия и самостоятельная отмена — по сроку того поставщика.

**Админка:**
- «Товары» и «Бренды» — вкладки по поставщикам и колонка «Поставщик» (бренд — во вкладке, если у него есть товары этого
  поставщика);
- «Посылки из США» → **«Поставки под заказ»**, с выбором поставщика; посылка принадлежит одному поставщику;
- «Поставщики» — карточка поставщика: вид, страна, сроки, гарантия.

## Что сделано (09.11.2026, ветка supply-sources)

- API: поставщики с видом (Ozon / местный / из-за рубежа), сроками и гарантией; «Где берём» и «Если на складе ноль» у товара;
  новый товар без отметок — по артикулу (VTL-H… iHerb, VTL-GH… iHerb + Glorious, OZN-… Ozon); строка заказа и поставка
  помнят поставщика; в одной поставке — один поставщик; у местной поставки нет этапов «отправлена / прибыла».
- Оплата при получении — для местного «под заказ»; если в заказе есть зарубежная строка — только предоплата.
- Сроки «из США» теперь у поставщика iHerb (Настройки → Справочники → Поставщики); старая карточка «Сроки и гарантия»
  в «Посылках из США» убрана, страница называется «Поставки под заказ».
- Админка: вкладки поставщиков в «Товарах» и «Брендах», колонка «Где берём», редактор поставщика, блок «Где берём» в товаре.
- Mini App: «Под заказ из США • 7–14 дней» / «Под заказ • 1–2 дня», значки «Из США» / «Под заказ», короткий трекинг
  местного заказа («Заказан у поставщика»), сообщения бота по поставщику.
- Миграция `20261119100000_supply_sources` проверена на vitalo_test; на vitalo_dev — только с разрешения.
