Прочитай `docs/PROGRESS.md`. Проверь невыложенные изменения: `git status --short`, текущую ветку и
`git log --oneline server/main..HEAD` (коммиты, которых нет на сервере; если remote `server` не настроен —
так и скажи).

Ответь пользователю 5–7 короткими строками по-русски, просто, без жаргона:

1. Где мы: текущий этап.
2. Что уже готово в текущем релизе.
3. Что осталось в текущем релизе.
4. Следующий шаг.
5. Невыложенные изменения: незакоммиченные файлы и коммиты, которых нет на сервере.
6. Открытые вопросы — одной строкой, только самые важные.

Ничего не меняй и не запускай, кроме чтения файлов и команд git выше. Секреты не показывай.
