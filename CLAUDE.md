# VITALO — правила для Claude

## Рабочая база данных

**Никогда не запускай seed или тесты на рабочей базе без прямого разрешения пользователя.**

- Рабочая база — `vitalo` (DATABASE_URL в `apps/api/.env`). Запрещено без разрешения: `npm run seed`,
  `npx prisma db seed`, `ts-node prisma/seed.ts`, любые тесты или скрипты, направленные на эту базу.
- Разрешение спрашивай каждый раз отдельно; прошлое разрешение не переносится на следующий запуск.
- Тесты по умолчанию используют отдельную базу `vitalo_test` (`apps/api/test/test-env.ts`,
  глобальная установка отказывается работать с базой без суффикса `_test`) — это не рабочая база.
- Причина: повторный seed однажды перезаписал остатки и снял резервы открытых заказов в рабочей базе.
